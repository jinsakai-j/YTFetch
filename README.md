# YTFetch

A clean, high-performance YouTube media utility.

Desktop GUI modern & cepat untuk mendownload video YouTube menjadi MP4 (hingga 1080p FHD) atau MP3 dengan integrasi `yt-dlp` & `FFmpeg`, dilengkapi fitur Clip Trimming dan Playlist Bulk Downloader.

## 🚀 Fitur Utama

1. **📥 Downloader & Clip (Tab 1)**:
   - Paste URL single video YouTube.
   - Preview thumbnail, judul, channel, dan durasi otomatis.
   - Output Video (1080p FHD, 720p HD, 480p) & Audio MP3 (320kbps, 128kbps).
   - **Timestamp Clip Trimmer**: Potong klip spesifik berdasarkan timestamp waktu mulai & selesai.

2. **📋 Playlist Manager (Tab 2)**:
   - Paste URL playlist YouTube untuk deteksi daftar video secara otomatis.
   - Pilihan Select All / Deselect All dengan checkbox untuk mengunduh banyak video sekaligus (bulk download).

---

## ⌨️ Shortcut System

- **`Ctrl + V`** : Paste otomatis URL dari clipboard & langsung jalankan fetch metadata.
- **`Enter`** : Mulai proses download.
- **`Esc`** : Batalkan proses download yang sedang berjalan.
- **`Ctrl + O`** : Buka folder penyimpanan hasil download di File Explorer.

---

## 💻 Cara Menjalankan Aplikasi

1. **Jalankan via Batch Launcher**:
   - Klik ganda pada `Run_YTFetch.bat`.

2. **Atau via Python**:
   ```bash
   python YTFetch.py
   ```
